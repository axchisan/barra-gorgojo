## 4 · Para iniciar la próxima sesión

Abrir Claude Code en `Documents/Dev/Apps/BarraGorgojo` y pegar:

> Vamos a seguir con la Barra del Gorgojo. Lee `AGENTS.md`, `docs/21-estado-2026-11-16.md`,
> `docs/18-roadmap-2026-11.md` y las «Reglas para trabajar en producción» de
> `docs/12-plan-de-trabajo.md`. Producción tiene datos reales: no probar ahí, usar el
> entorno de pruebas. Pregúntame antes de cada despliegue a producción. Empecemos por
> 21 §3.

Comandos:

```bash
pnpm install && pnpm build   # en un clon nuevo: build antes de las pruebas del Worker
pnpm verificar               # tipos + Vitest (dominio y Worker real)
pnpm -s build && pnpm test:e2e   # Playwright; si una falla, repetirla sola
pnpm desplegar:pruebas       # entorno de pruebas (barra-pruebas)
node scripts/admin.mjs .dev.vars.produccion foto migracion/<nombre>.json   # foto, solo lectura
pnpm desplegar               # producción, solo con permiso; foto antes y después
```

Para revisar algo de producción sin tocarla: la foto (`scripts/admin.mjs … foto`) y leerla
con `node` o `npx tsx` usando las funciones de `src/dominio` (así se revisó la cuenta del
cambio de plata). Cualquier corrección en producción la hace una persona desde la app.
